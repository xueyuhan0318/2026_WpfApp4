# WPF小作家
2026/11/11

## 功能
1. 引入extended toolkit
2. 使用多視窗
3. 新增一個DocumentViewer視窗，用來顯示和瀏覽文檔內容
4. 在主視窗MainWindow中新增一個按鈕，典籍後可以打開DocumentViewer視窗
5. 在DocumentViewer視窗中新增一個RichTextBox，用來顯示文檔內容，並且可以進行編輯
6. 使用CommandBinding來實現RichTextBox的基本編輯功能，例如剪下、複製、貼上等
7. 在Editing ToolBar中新增文字格式的按鈕，包含加粗、斜體、底線、下劃線、字型顏色等功能
8. 使用第三方元件ColorPicker來實現自己顏色的選擇功能
9. 新增變更文字自行的ComboBox，讓使用者可以選擇不同的字型
10. 新增變更文字大小的ComboBox，讓使用者可以選擇不同的字型大小
